نبض المدرسة - تفعيل الحسابات السحابية عبر Supabase + Vercel
============================================================

هذه النسخة تغيّر تسجيل الدخول وحسابات الطلاب والمعلمين إلى Supabase Auth.
لا يتم وضع service_role داخل index.html أو أي ملف يصل للمتصفح.

الخطوة 1 - Supabase
-------------------
1) افتح مشروع Supabase الخاص بالمنصة.
2) افتح SQL Editor ثم New query.
3) افتح الملف: supabase/schema.sql
4) انسخ محتواه كاملًا، الصقه في SQL Editor واضغط Run.

الخطوة 2 - إنشاء حساب الإدارة لأول مرة
---------------------------------------
1) في Supabase افتح Authentication ثم Users.
2) اختر Add user / Create new user.
3) أنشئ حساب الإدارة بالبريد وكلمة المرور التي تريد استخدامها في المنصة.
4) فعّل/اختر إنشاء المستخدم كبريد مؤكد إن ظهر الخيار.

ملاحظة: لا تحتاج لإضافة سجل admin يدويًا إلى جدول profiles. أول مرة يسجل هذا البريد دخوله،
سيقوم النظام بإنشاء ملف الإدارة تلقائيًا بشرط أن يطابق متغير ADMIN_EMAIL في Vercel.

الخطوة 3 - متغيرات Vercel
--------------------------
في مشروع Vercel افتح Settings > Environment Variables وأضف:

SUPABASE_URL              = رابط مشروع Supabase
SUPABASE_ANON_KEY         = المفتاح العام anon / publishable key
SUPABASE_SERVICE_ROLE_KEY = مفتاح service_role السري
ADMIN_EMAIL               = بريد حساب الإدارة الذي أنشأته في Authentication > Users

مهم جدًا:
- SUPABASE_SERVICE_ROLE_KEY يوضع في Vercel فقط.
- لا تضعه داخل index.html أو cloud.js أو GitHub.

بعد إضافة المتغيرات اعمل Redeploy للمشروع.

الخطوة 4 - GitHub
-----------------
ارفع جميع محتويات هذه الحزمة إلى مستودع GitHub الخاص بالمشروع، وليس index.html وحده.
يجب أن تكون هذه العناصر موجودة في الجذر:
index.html
cloud.js
supabase-config.js
package.json
api/
supabase/
والصور

بعد push إلى GitHub سيعيد Vercel النشر تلقائيًا غالبًا. إن لم يحدث، اختر Redeploy.

الخطوة 5 - الاختبار
-------------------
1) افتح رابط Vercel.
2) سجل دخول الإدارة بحساب Supabase الذي أنشأته.
3) من الإدارة أضف طالبًا جديدًا ببريد وكلمة مرور.
4) افتح نافذة Incognito أو هاتفًا آخر.
5) سجل دخول الطالب بنفس البريد وكلمة المرور.

إذا دخل من الجهاز الآخر، فالمزامنة السحابية للحسابات تعمل.

ما تم تحويله للسحابة في هذه النسخة
---------------------------------
- تسجيل الدخول: Supabase Auth
- إضافة طالب: حساب Auth + profile سحابي
- إضافة معلم: حساب Auth + profile سحابي
- تعديل بريد/كلمة مرور الحساب بواسطة الإدارة
- حذف الطالب/المعلم من Auth والملف السحابي
- قراءة قائمة الطلاب والمعلمين للإدارة من Supabase

ملاحظة:
بعض أجزاء المنصة الأخرى (مثل بعض الجداول/الإعلانات/بيانات العرض) قد تظل تستخدم LocalStorage
إلى أن يتم نقل وحداتها إلى جداول Supabase مستقلة. هذه النسخة تعالج مشكلة الحسابات وتسجيل الدخول من أي جهاز.
